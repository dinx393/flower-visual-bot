# История версий

## 0.5.0 — 2026-09-23

- Каждый план генерации теперь содержит неизменяемый паспорт решения: активные правила, выбранные кейсы, анти-уроки и прямые указания сотрудника с точными источниками.
- Добавлен единый формат объяснения, который может показать любая оболочка агента без реконструкции причин задним числом.

## 0.4.1 — 2026-09-15

- По решению пользователя кейсы №005, №007 и №008 исключены из активного набора утверждённых эталонов и памяти агента.
- История «Стильной коробочки» перенесена в архив аудита и не участвует в поиске референсов.

## 0.4.0 — 2026-09-14

- Добавлена эпизодическая память ядра: одобренные карточки и истории правок индексируются и кэшируются по отдельным файлам.
- План генерации выбирает релевантные полные записи опыта и до трёх существующих изображений-эталонов, не подставляя всю библиотеку в каждый запрос.
- В план записываются версия памяти, идентификаторы выбранных кейсов и пути к референсам.
- Добавлен `visual_context` для будущего результата анализа исходной фотографии.
- Исправлена точка запуска контейнера после переименования загрузчика знаний.

## 0.3.4 — 2026-09-13

- Кейс «Шикарные лилии», 210р переведён из `positive_feedback` в одобренный калибровочный эталон №004.

## 0.3.3 — 2026-09-13

- Введён статус `positive_feedback`: удачная работа может стать калибровочным кандидатом без ложного перевода в опубликованный эталон.
- Добавлен первый кейс с положительной обратной связью: «Шикарные лилии», 210р.
- Навык теперь фиксирует одобрения, позитивные кандидаты и запросы на правку в общей истории проекта.

## 0.3.2 — 2026-09-13

- Добавлен потокобезопасный кэш полного набора документов `knowledge/`: они читаются один раз и переиспользуются из памяти.
- При изменении одного Markdown-документа перечитывается только он; полный контекст для модели собирается из него и неизменённых фрагментов, уже находящихся в памяти. Добавленные файлы читаются один раз, удалённые исключаются без чтения.
- Каждый план теперь хранит версию полного снимка знаний, по которому он был собран, для аудита результата.

## 0.3.1 — 2026-09-13

- Добавлен третий одобренный калибровочный кейс «Повод улыбнуться» с файлом-эталоном.
- Уточнено правило иерархии: смысловая script-строка в составе заголовка не должна превращаться в мелкую подпись.

## 0.3.0 — 2026-09-12

- Убраны отдельные режимы скорости и локальная отрисовка: любую готовую сторис всегда создаёт генератор изображений.
- Для всех типов вмешательства введён единый производственный профиль: `gpt-image-2.5-flare`, качество `medium`, один запуск, лимит генерации 120 секунд.
- Скорость достигается не урезанием качества, а предсборкой запроса, кэшированием знаний, отсутствием скрытых повторов и измерением времени каждого этапа.
- Добавлен второй одобренный калибровочный кейс «Стильная сумочка» с файлом-эталоном для будущих регрессионных проверок.

## 0.2.0 — 2026-09-11

- Введены явные элементы макета: заголовок, цена, дополнительная надпись, декор и сервисная строка.
- Дополнительная надпись ограничена одной; сервисная строка возможна только при подтверждённых данных.
- Закреплён контраст двух начертаний внутри заголовка: serif + script, когда это поддерживает конкретный кадр.
- Добавлена иерархия масштаба: цветы всегда главный визуальный центр, заголовок не должен быть ни гигантским, ни микроскопическим.
- Цена усилена как вторичный акцент; предпочтительное место — нижняя правая свободная зона.
- Добавлен первый одобренный калибровочный кейс «Розовое облако».
